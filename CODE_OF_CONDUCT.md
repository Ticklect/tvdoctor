# Code of Conduct

TVDoctor is built by people with different backgrounds, abilities, identities,
and levels of experience. Everyone participating in this project must help keep
that collaboration safe, professional, and useful.

## Expected behaviour

- Be respectful, specific, and patient.
- Critique ideas, evidence, and code—not people.
- Make room for questions and different communication styles.
- Give credit, respect privacy, and obtain consent before sharing another
  person's work or information.
- Accept correction, repair harm where possible, and move the technical work
  forward.

## Unacceptable behaviour

- harassment, threats, stalking, discrimination, or sexualised conduct;
- insults, personal attacks, deliberate humiliation, or sustained disruption;
- publishing private information, credentials, or private communications;
- pressuring someone to disclose identity, disability, location, employer, or
  other personal details;
- retaliation against a good-faith report;
- using project spaces to promote illegal access to applications or devices.

## Scope and enforcement

This policy applies in repository discussions, reviews, issues, project chat,
events, and when someone represents the project publicly.

Report conduct concerns privately to a maintainer through the repository host.
Do not open a public issue that identifies a target of harassment. Maintainers
may edit or remove content, issue a warning, restrict participation, or ban a
participant. They should protect reporter privacy, avoid conflicts of interest,
and explain decisions to affected people when it is safe to do so.

Good-faith disagreement about technical evidence is welcome. Harassment framed
as code review is not.
