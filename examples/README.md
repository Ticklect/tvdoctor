# TVDoctor examples

Start with the [examples guide](../docs/examples.md). Its first workflow runs the
navigation audit without an authored D-pad route, then shows CI, baseline
comparison, and replay. Normal navigation runs produce `navigation-graph.json`
and `navigation-graph.md` alongside `inventory.json` in the report bundle.

The executable files in this directory support bounded examples such as baseline
comparison and report summarisation. They are evidence only for the behavior they
exercise; a pasted snippet or local package import is not a compatibility claim
for an arbitrary TV application.

Benchmark claims must follow [the benchmarking guide](../docs/BENCHMARKING.md).
